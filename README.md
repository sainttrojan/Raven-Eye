# 🏢 نظام Raven Eye للبحث العقاري

نظام احترافي للبحث عن العقارات والشقق المعروضة من المالك مباشرة. يوفر النظام واجهة مستخدم (لوحة تحكم) لإدارة عمليات البحث بسهولة، مع إمكانية تصدير النتائج إلى ملفات Excel.

---

## ✨ المميزات
- **واجهة احترافية**: تصميم هادئ (دارك مود + ذهبي شامبين) مناسب لبيئة العمل.
- **فلاتر متقدمة**:
  - تحديد **تاريخ النشر** (آخر 24 ساعة، أسبوع، شهر).
  - تحديد **الموقع** (PropertyFinder, Dubizzle, Aqarmap, أو الجميع).
  - البحث بـ **تطابق الجملة بالكامل**.
- **تصدير البيانات**: تحميل النتائج مباشرة في شيت Excel منسق ويدعم اللغة العربية.

---

## ⚙️ طريقة التشغيل

لتشغيل لوحة التحكم (Web App)، قم بفتح موجه الأوامر (الشاشة السوداء) داخل مجلد المشروع واكتب الأمر التالي:

`powershell
.\uv_extracted\uv.exe run streamlit run app.py
`

سيفتح المتصفح تلقائياً على الواجهة الرئيسية.

---

## هيكل المشروع
- pp.py: الملف الرئيسي لتشغيل واجهة المستخدم (Streamlit).
- scrapers/google.py: محرك البحث الأساسي الذي يجلب البيانات باستخدام ScraperAPI.
- main.py: سكربت تشغيل بديل للبحث من الشاشة السوداء مباشرة بدون واجهة.
- .streamlit/config.toml: ملف تخصيص الألوان والثيم.
